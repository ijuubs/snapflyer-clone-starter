# SnapFlyerClone starter
Independent Kotlin + Jetpack Compose Android starter based on the routes/features found during local APK analysis. It does not use SnapFlyer's private API or copied assets.

Included: home/search, sample flyers/offers/stores, navigation drawer, bottom navigation, placeholder sections, and a draft Supabase schema.

Open in Android Studio and sync Gradle. Android SDK 35 and Java 17 are configured. This starter uses sample data only; no live backend is connected. Review and add Supabase Row Level Security policies before production. Never put a Supabase service-role key in an Android app.
